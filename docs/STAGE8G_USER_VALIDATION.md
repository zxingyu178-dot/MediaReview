# Stage 8G 用户验收步骤

本清单用于 Alpha10 发布后的真实手机与家庭 LAN 验收。自动化 fixture 不代替这些验收；目前均未执行。

1. 更新到 code17 / 2.0.0-alpha10。首次安装仅展示当前更新说明；升级展示所有未读说明，关闭后重新启动不再自动弹。
2. 在首页选择文件夹、类型与排序，加载两页并滚动到中间。打开搜索后空关键词只能显示历史或输入提示。
3. 输入可匹配多页的关键词，确认首屏只加载一页、接近尾部才追加；快速改词时最终结果对应最后一个关键词。
4. 在追加时断网，确认已经加载的结果仍可看、显示“加载更多失败 · 重试”；恢复网络后显式重试继续加载。
5. 从搜索中间打开视频，返回后仍是原关键词、已加载结果和滚动位置。关闭搜索后首页原文件夹、排序、页数和位置保持。
6. 收藏三个视频与三张图片。从各自中间项打开，确认视频上下条与图片左右滑动只遍历同类型收藏。
7. 图片查看器原位取消收藏、重新收藏、再次取消，图标与操作一致，位置不跳到第一项；返回收藏页后取消项消失。
8. 使用家庭 LAN 的真实服务器复核播放、图片与请求失败恢复；记录设备、网络、应用版本和复现步骤，避免记录 Token 或私人媒体路径。

Server 代码保持1.2.2 / Contract2。官方升级桥仍 BLOCKED_EXTERNAL_CONTROLHUB_CONTRACT，本阶段不执行生产升级或手机数据迁移。

收藏全量 API 与逐项媒体信息获取记录为 P1 PERFORMANCE DEBT；本阶段没有性能退化证据，不预先改 Server 协议。完成 Stage8G 后停止，不自动进入8H。
