## 五、中期审查关注项

1. **交付一致性（高优先）**：正式/候选/源码/日用四层存在版本差。每次交付锁定同一APK哈希、Server版本、桥能力和源码提交；禁止借旧测试证明新产物。
2. **核心体验未闭环（高优先）**：批阅与大相册不能仅依靠短视频、SQL性能或JVM结果判定。缺少设备就是未验，不继续增加重复软件测试替代。
3. **部署可恢复性（高优先）**：队列现在空闲，但实例与工作流已变化；重新预检、完整备份、经官方入口维护、核实实际释放及启动身份，再做组合验证。自动升级事务桥仍未接通，不绕过。
4. **续审完整性（中优先）**：图片身份已恢复不等于序号和前后浏览完整；本次按用户批准补齐，不采用只改文案的替代方案。
5. **资源与质量保障（中优先）**：采集真实设备首屏/滚动/播放与电脑CPU/内存/日志增长基线，再据症状优化；MediaReview无GitHub Actions工作流，当前本地定向验证不能称CI通过。是否新增最小CI作为后续工程决策，不在本轮自动搭建。
