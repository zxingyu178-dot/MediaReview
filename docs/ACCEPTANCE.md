# V1 验收标准

## P0 — 必须全部通过

- [ ] Android 能自动发现 Server。
- [ ] 手动 IP 可连接。
- [ ] 一次配对码正常工作。
- [ ] 可读取 Jellyfin 多个媒体库。
- [ ] 可勾选参与 MediaReview 的媒体库。
- [ ] 媒体墙可浏览视频和图片。
- [ ] 封面大小/列数可调整并保存。
- [ ] 排序功能可用。
- [ ] 筛选功能可用。
- [ ] 视频长按可雪碧图预览。
- [ ] 原媒体文件夹没有产生缓存垃圾文件。
- [ ] 普通视频播放稳定。
- [ ] 视频流不经 FastAPI 大流量转发。
- [ ] 批阅模式可上下刷。
- [ ] 滑动结束后下一视频才播放。
- [ ] 当前视频加载优先于下一视频。
- [ ] 横屏视频竖屏居中。
- [ ] 点赞写入本项目数据库。
- [ ] 点赞不修改原文件。
- [ ] 喜欢页面正常。
- [ ] 删除只进入待删除。
- [ ] 可撤销待删除。
- [ ] 最终删除需确认。
- [ ] 删除成功/失败有明确结果。
- [ ] 删除审计日志存在。
- [ ] 同一批阅会话不重复出现已刷项目。
- [ ] 新批阅会话允许未操作媒体再次出现。
- [ ] 批阅断点恢复可用。
- [ ] 完全重复检测可用。
- [ ] 完全重复不会自动删除。
- [ ] 管理后台可查看状态。
- [ ] 雪碧图任务可查看。
- [ ] 缓存可清理。
- [ ] ZIP 自动部署可在非开发电脑完成。
- [ ] 部署电脑无需安装 Python 开发环境。
- [ ] FFmpeg 随包或自动就绪。
- [ ] Server 可开机自启。
- [ ] Android 用户可见文案均为中文。

## P1 — 强烈建议全部通过

- [ ] 大媒体库分页不卡顿。
- [ ] 10,000+ 媒体情况下启动可接受。
- [ ] 雪碧图后台生成不影响播放。
- [ ] 当前视频缓冲时会抑制下一条预加载。
- [ ] Wi-Fi 短暂断开后可恢复。
- [ ] Jellyfin 重启后可恢复。
- [ ] 图片大图加载有降采样。
- [ ] 删除批次单个失败不会终止全部。
- [ ] 日志支持一键导出。
- [ ] Server 配置支持备份与恢复。
- [ ] 数据库迁移支持升级。
