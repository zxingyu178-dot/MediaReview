# 手机深色媒体界面、刷新与动效

用户报告刷新图标闪动、生图切换无动画、整体像demo；明确选择深色媒体风，并要求电脑开发完成后再通知连接手机。本轮不连接真实手机、不修改服务端/生产服务/真实媒体。

## 变更

- 全局补齐暗色语义色、容器/危险色、字体层次、圆角；导航有选中容器与Tab语义、48dp触控；首页模式切换、收藏标题与整理入口统一层次。公共媒体卡及历史页面继承主题，未逐屏重排全部历史页面。
- 生图库工具栏/筛选面板/图卡深色层次及间距；批量和版本对比页图卡统一圆角，批量窄卡操作换行，放大按钮48dp，提交使用公共主按钮。所有业务事件与危险确认保持。
- 刷新直接根因：withFeedRead反复切syncing，旧UI把多种查询操作设为disabled色，刷新Icon被整个替换为spinner。现查询操作不因后台读取批量变灰，刷新仍防重复但保留图标，只角落叠加进度；标签稳定。图卡request记忆化是额外稳定性收敛，不声称已证明每次new request必然重发。
- 切图按身份创建同步transition，首图/同ID更新不动画，前后方向与审核后相同index替换分别判断。静态旧预览无交互/回调，当前仅一份ZoomableImage；新图就绪后190ms/40dp滑动淡入，冷加载最多等待1200ms后进入当前错误/重试态。过渡期间审核/收藏/详情门禁；原Initial手势、双指与拖图边界保留，不改共享缩放/播放器核心。
