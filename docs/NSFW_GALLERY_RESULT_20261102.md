# 生图图库与浏览位置恢复

2026-11-02。按用户确认：默认进入图库，点击图片进入审核。仅修改 MediaReview；未修改 NSFW 生图模块、数据库或生成队列。

## 改动与原因

- 原审核页只在内存保存 currentId，重建后从首图开始。现在复用已有 DataStore，按规范化服务地址独立保存审核图片 ID，以及图库首个可见图片 ID/滚动偏移；重新配对同一服务也读取原位置。
- 新增三列懒加载图库，支持点选、当前项标记、继续上次、审核状态和缩略图失败重试。审核页可返回图库，原图、详情、提示词评分及成功回执后前进逻辑沿用现有实现。
- 新图追加队尾；恢复目标尚未同步到时显示恢复中，不用首图覆盖旧位置。用户主动选图可结束等待；完整历史核对后目标不存在才明确提示回退。图库位置读取失败时，自动布局不能覆盖旧值；用户实际滚动后才保存新位置。图库位置与审核位置独立读取，避免单个读取失败阻断另一项恢复。
- 关键文件：`NsfwGallery.kt`、`NsfwReviewScreen.kt`、`NsfwReviewViewModel.kt`、`NsfwBrowsePositionStore.kt`、`NsfwProfileStore.kt`、`NsfwModule.kt`；沿用现有版本/发布说明合同升为 Alpha31/code38。无迁移、新网络框架或新常驻服务。
