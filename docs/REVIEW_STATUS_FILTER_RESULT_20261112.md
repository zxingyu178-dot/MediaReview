# 手机审核状态筛选补齐

## 范围与实现

用户授权先补齐筛选。沿用筛选面板，提供全部、只看未审核NEW、已保留KEEP、已淘汰REJECT、已归档ARCHIVED，新增隐藏已淘汰NOT_REJECTED（保留NEW/KEEP/ARCHIVED）。当前筛选在图库显示短标签，状态按服务来源单独保存，空结果仍记住选择；全部显式写ALL，不依赖某张图片的浏览锚点。

复用status参数、filters回显和数据库查询，在服务端分页前过滤；游标绑定条件，不能跨状态复用。新增mobile_gallery_review_filter_v1门禁；旧桥隐藏新选项并阻止恢复不支持的查询，初始偏好不支持时明确提示当前显示全部。原有分类、收藏、搜索能力不混作状态排除能力。

手机自己审核后，若图片不再符合条件，重新查询同条件以更新总数/页并选择相邻锚点；仍符合条件则维持原有下一张逻辑。撤销目标已移出时，核对回执身份与严格前进的revision后重查；异常回执保留核对对象，绝不自动重发POST。列表读取期间锁定提交，读取失败提示审核已保存/列表待刷新；无锚点重查成功也加载首图详情。
