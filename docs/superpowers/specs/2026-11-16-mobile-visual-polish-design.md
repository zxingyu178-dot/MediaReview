# 手机深色媒体界面与刷新动效

用户报告刷新时图标闪烁、生图切换没有动画、界面与按钮像演示版。已明确选择“深色媒体风：图片优先、克制精致”。本轮先电脑开发及验证，完成后通知连接手机，不主动连接/安装真实手机。

视觉：深炭黑背景、分层中性表面和克制强调色；统一圆角、字号、间距、描边与按钮主次。媒体卡片以图片为主，精简常驻文字；主导航有清晰选中态，危险操作保持明确标签和独立样式。图标触控区至少48dp并有中文无障碍说明。

刷新：先确定重组、enabled透明度、图片请求及列表清空等真实原因。背景同步保留图片与可用工具栏，不制造整片禁用变暗/恢复；重复刷新请求有内部防重，进度局部显示，必要的提交锁不放开。

切图：约200ms方向滑动与淡入，跟随上一/下一张方向；同imageId刷新不触发动画。现图保持唯一交互与唯一缩放/就绪状态所有者，出场层不可交互、不发请求或污染回调。缩放拖图保持原手势边界，不扩改播放器核心。

范围：手机主题/公共控件/导航及主要页面、生图库/筛选/看图；服务端、真实数据、部署不在本轮。必要行为回归测试，避免样式实现镜像测试和无关全套。模拟器只用合成媒体，验证范围与真机结论分开。

自查：风格已获批准，刷新和切图分工明确，不引入新基础设施或真实媒体写入。
