# 审核与目录性能目标

基线为 e5e4350。逐个验收后再进入下一目标。使用合成媒体、本地测试与只读证据，本轮不接手机。

1. 连审可操作时间。分别记录选图到清晰预览、选图到按钮可用。现代图库当前条目有合法版本与时间戳时，清晰图可审核，不阻塞在详情请求。缺失版本、冲突、撤销和旧桥走原安全路径。验收包含详情挂起、错误版本、响应冲突及正常写入。
2. 目录查询。独立测冷树、命中缓存、目录计数、取页及首封面。用隔离合成库比较查询计划和 p50/p95，先确定哪段占主要耗时，再考虑存储目录归属、索引及缓存。相同媒体 ID、顺序、直接／递归和跨库范围必须完全一致。
3. 图片传输。带限速的连续 30 张样本统计同图请求次数、字节、缓存命中、清晰就绪时间。仅有重复请求证据时实现合并。快速连续操作及反向滑动单测覆盖。
4. 视频反馈与目录布局。验证提交中、服务器确认和失败回到原条目的区分。用 320dp 和大字体验证底部关键操作可见，缩减首屏筛选占用。
5. 生图进度。需要电脑端审核桥提供同一队列快照。核对 3/6、剩余 20 段、跨段重置和断线时隐藏旧数据。

## 目录基线

8,000 条合成视频、1,642 个目录节点，通过项目原路由和隔离 SQLite 请求。冷树 259 ms，暖树 8 ms。20 次针对单库目录的明细请求结果均为 10 项，p50 85 ms，p95 114 ms。首条明细内两个计数的 SQL 执行样本约 4 ms 和 35 ms，当前页查询启动约 0.6 ms。驱动读行、序列化和客户端首张封面另计。本轮基线未复现生产记录中的秒级延迟。

## 第一阶段结果

旧实现复现详情挂起时发出 0 次审核请求。修复后同场景发出 1 次，沿用列表时间戳，审核状态和撤销正确，晚到的旧详情不会覆盖新版本。审核 ViewModel 108 项和桥接口合同 43 项通过，Debug APK 构建成功。新增清晰预览与操作就绪的独立计时，尚无设备慢网体感测量。

## 第二阶段实现边界

保留原目录规范化、目录 ID、库归属和可用性判断。通过 SQLite 表达式索引加速现有谓词，避免为旧记录回填新字段。迁移只加索引，降级只移除索引。使用真实目录路由采集计数查询的执行计划，并在同一批合成数据下比较迁移前后页内容、范围和耗时。首张封面属于客户端端到端计时，单独记录。

0019 迁移的配对对照，8,000 条合成视频，同库每组 20 次。直接目录 p50 48.047 → 29.741 ms、p95 70.479 → 43.095 ms，目录计数 SQL p50 8.998 → 0.043 ms。递归代表样本第 2 页 p50 47.459 → 26.738 ms、p95 59.815 → 41.211 ms。索引前后目录树、总数、媒体 ID 和排序一致；真实路由 EXPLAIN 使用目录表达式。0018 → 0019 → 0018 验证保留路径与 ID，完整性检查正常。最终 41 项目录与归属回归通过，删除回执专项另轮通过。

冷树在配对样本约 191 ms，暖树约 10 ms。本改动主要改善目录明细，客户端首封面和先前生产秒级异常仍待联测。

## 第三阶段诊断

使用隔离的 Android 35 模拟器、纯合成 PNG、每 40 ms 提供 4096 字节的模拟 HTTP 响应。连续执行 30 次单图保留，统计请求、读取的载荷字节、Coil 加载来源、按钮就绪时间。诊断红例在第 1 张采集到 4 次预览解码成功，同时记录了适屏时多发 1 次原图请求（404），按钮仍禁用。界面调用交换了当前页和原图加载两个位置参数，源码已改为显式命名参数；附加保护在原图未请求时不展示原图失败。复跑使用修复版 App 与同一测试条件，4 项模拟器用例通过。

30 张连续审核共 30 个预览 HTTP 请求，0 重复，适屏原图 HTTP 为 0，客户端实际读取响应体 1,306,260 字节。Coil 成功结果为网络 30、内存缓存 57、磁盘 1，包括预取与切换帧。测试轮询测得按钮就绪 p50 228 ms、p95 339 ms，包含界面测试同步时间。该场景不支持增加合并请求的复杂度。仍需按真实网络条件验证体感。

## 第四阶段验收边界

手动视频审核可先翻页，界面持续追踪同一请求到服务器回复。请求处理中只显示提交状态，确认后才显示已保存。失败保留原媒体身份，在会话内可跳回并重试；结束或切换会话时旧回复不覆盖新界面。目录页合并类型筛选与排序，子目录按需展开，在窄屏及大字体下核对底栏和首屏封面。

207 项 Android 定向 JVM 测试通过，覆盖视频审核、目录分页、生图审核及桥接口合同。视频保存状态和窄屏准备时的底栏验证通过。320dp 模拟器单独运行合成 HTTP 视频长按用例，验证按住为 2 倍速、松手恢复原速度。播放中的大字布局用例首轮在启动视频时超时，独立重跑通过，进度条触控区在底部操作区上方。 为缩短首屏，子目录默认收起。初轮大字号的类型标签宽度溢出，在大字模式给三个按钮等分整行后，320dp／200% 字号下验证标签完整、排序可用和首个视频卡片可见。最终同轮 5 项模拟器用例通过，包括保存提示，视频准备时底栏及间距，目录导航分页、筛选排序和封面预取。长按倍速和播放中布局分别独立复跑通过。真实网络封面首显、真机和正式服务未验证。

模拟桥验证支持能力时展示 3/6、剩余 20 段，换段时改为 1/6、剩余 19 段。断线隐藏旧进度，进入后台停止轮询，回前台重新读取。旧桥未声明能力时跳过进度请求。电脑端实际接口尚待接入，读取约定见 [移动审核接口](../../integration/NSFW_MOBILE_API_CONTRACT_V2.md#可选扩展-mobile_generation_progress_v1)。
