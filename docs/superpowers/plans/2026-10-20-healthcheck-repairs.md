# 体检问题修复实施计划

> 按用户批准的体检结论，在当前开发分支串行实施；复用现有测试，不启动生产升级。

**目标：** 修复跨库归属丢失及已确认的界面问题，保留稳定媒体 ID 和用户状态。

**方案：** 新增 `media_library_membership` 复合主键表，按库记录同步代次。查询使用归属条件去重，只有全部目标库同步成功才清理这些库未见的关系；无其他归属的媒体才失效。原字段保留兼容本地媒体源和旧数据。

**技术栈：** SQLAlchemy / Alembic / SQLite，Kotlin / Compose。

## 约束

- 不操作真实媒体、不清除手机数据、不替换播放器、不自动部署生产。
- 迁移只新增表并回填旧归属；历史丢失关系需要正常重新同步恢复。升级前备份数据库；降级若有额外归属则拒绝有损操作，恢复备份。
- 只跑改动相关测试；不重复全量 connected / 全套服务端与 JVM。
