# 手机视觉与动效实施计划

**Goal:** 修复刷新闪烁，补齐切图动画，统一深色媒体界面与按钮质量。

**Architecture:** 沿用Compose主题、公共控件和现有数据层；局部同步状态与稳定图片身份，现图唯一交互的切图过渡。

**Tech Stack:** Kotlin/Compose、Coil、JUnit，既有Android模拟器。

- [ ] 刷新域：定位disabled状态/请求/列表身份原因；先行为测试RED，再最小修复；图库视觉同步整理。
- [ ] 动效域：方向、同图更新及手势边界先测试RED；安全切图过渡及浮层整理。
- [ ] 视觉域：主题token、公共控件、导航、首页/收藏/整理样式，保持行为及危险操作保护。
- [ ] Root串行运行定向测试与编译；复查并用合成媒体模拟器查看主要界面，不操作真实媒体。
- [ ] 更新结果/版本说明，准备递增候选；提交推送，明确尚需真机验收并通知用户连接。
