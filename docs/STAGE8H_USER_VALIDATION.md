# Stage8H 手机验收路线

预计 10～15 分钟。使用 Alpha11 与 Server 1.3.0，在同一家庭网络中完成配对，准备一个有多级目录和相册的媒体库，以及至少三段真实视频。当前开发验收只使用合成素材；手机和家庭网络的结果由这次亲自体验确认。

本阶段仅交付服务器安装包，不部署生产服务器；正式升级桥仍为 `BLOCKED_EXTERNAL_CONTROLHUB_CONTRACT`。服务器尚未升级时，先保留当前运行环境，待官方升级入口具备条件后执行本路线。

1. 首页切换单列、双列：刚才浏览的媒体应仍在附近。
2. 首页上滑：顶部收起；再下滑：顶部恢复，列表不回到最上方。
3. 点分类进入多级文件夹，再沿面包屑返回：层级和当前目录内容正确。
4. 打开图库：相册封面能正常显示。
5. 进入一个相册，退出再进入：先立即显示刚才的内容，刷新时不整页清空。
6. 打开视频，拖动底部进度条：实际画面跳到所选位置。
7. 双击视频右侧、左侧：分别前进、后退约 10 秒。
8. 横滑视频：显示进度提示，松手后实际跳转。
9. 长按视频：临时 2 倍速；松手恢复原速度。
10. 长按后向上滑：锁定 2 倍速，松手仍保持。
11. 再长按：解除锁定并恢复原速度。
12. 进入批阅，横滑视频：调整进度，当前视频不换页。
13. 在批阅上下滑：切换视频，旧视频不继续出声。
14. 拖动批阅底部细进度条：松手后实际画面跳转。
15. 连续播放多个真实服务器视频，切换和返回：记录任何卡顿、黑屏、归零或离开后仍出声的问题。

如遇异常，记录步骤编号、视频显示名和现象即可；不需要发送配对密钥、请求头或其他凭据。
