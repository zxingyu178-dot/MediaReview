# MediaReview Android UI 重构计划（2026-10-25）

> 决策人：用户；执行：Codex；Lead 只做规划、复核、测试与验收。本文件是 UI 重构的唯一需求基线。
> 目标产物：Android 2.0.0-alpha17（暂定，实际版本在 P5 再定），服务端/API/本地源删除语义**不变**。

## 1. 用户反馈与目标

用户对当前 UI 的不满集中在四处：
1. **主界面操作**杂乱：搜索、数据源、排序筛选、单双列、文件夹 chips、模式切换堆在顶部，层级不清。
2. **文件夹打开**体验差：进入/后退、面包屑、列表与网格混排不直观。
3. **图片相册预览与查看**不沉浸：大图查看、滑动、缩放、信息展示需要重做。
4. **批阅模式**可优化：控件过多、进度感弱、预览不够好。

目标风格：**Google Photos 式相册体验 + 文件夹分类**。视觉关键词：沉浸、留黑、少控件、大图、顺滑手势、明确层级。

## 2. 设计原则

1. **内容优先**：默认满屏媒体，控件按需出现/自动隐藏；不使用厚重卡片边框。
2. **两层导航**：首页（时间线/全部媒体 + 分类入口）→ 目录/相册（网格）→ 大图/播放器。任何层级都能用系统返回手势正确回退。
3. **手势优先**：图片查看支持左右翻页、双指缩放、双击缩放、下滑关闭；批阅支持滑动决策；所有手势同时保留可点击按钮作为可达性兜底。
4. **零数据改动**：不改 Repository/API/Server；只重写 Composable 与 UI 状态映射；保留分页、缓存、预取、数据源切换等既有行为。
5. **性能不回退**：Coil 封面加载、窗口预取、分页阈值、Compose 重组边界必须保留并优化，不引入新的大型依赖。
6. **中文界面**：所有用户可见文案中文；错误/空态/加载态完整。
7. **测试可维护**：现有 JVM 测试与 testTag 尽量保留；删除/重命名的组件需同步更新测试，禁止削弱断言。

## 3. 目标信息架构

底部导航（保留现有入口，视觉重做）：
- **相册（首页）**：全部媒体时间线 + 分类 chips + 搜索 + 排序筛选（收进顶部/底部弹层）。
- **整理**：重复项、库管理、删除队列（现有功能保留）。
- **我的/设置**：数据源、播放诊断、版本信息（可并入整理页的二级入口）。

首页结构（从上到下）：
1. 半透明/渐变顶栏：标题"媒体库" + 搜索图标 + 更多（排序/筛选/单双列/数据源）。
2. 分类 chips 横向滚动：全部 / 各目录（含"更多"弹层）。
3. 主体：无边框大缩略图网格（2/3 列自适应，间距 2–4dp，圆角 2–6dp），按日期分节（月/日小标题，可选）；封面右上角显示视频时长，左上角显示是否已在待删除队列。
4. 滚动时顶栏收起，向下滚动回到顶部时展开；下拉可刷新。
5. 空态/错误态/加载骨架屏统一组件。

## 4. 各页面重构规格

### 4.1 首页 HomeScreen
- 顶栏重做：不再全部平铺；搜索进入独立全屏搜索页（输入框自动聚焦），返回恢复位置。
- 分类 chips 保留但视觉弱化（pill、选中态明显、可横向滑动）；点击进入对应目录。
- 网格：统一 `MediaThumb` 组件（图片/视频统一尺寸与占位、失败重试、加载渐变占位）；视频显示时长角标；支持双列/三列切换（图标按钮或菜单）。
- 排序/筛选：底部弹层（BottomSheet），交互与现有语义一致（时间/名称/大小/类型，筛选类型/来源/是否待删除）。
- 保留分页/预取/位置恢复逻辑；重构时不得改动 ViewModel 数据流语义，必要时只加纯 UI 状态。
- "文件夹"入口：首页 chips 之外，保留"浏览文件夹"入口进入目录浏览器。

### 4.2 目录浏览 FolderBrowserScreen
- 全屏页面：折叠顶栏（返回 + 当前目录名 + 更多菜单），下方面包屑 chips 可横向滚动、点击跳级。
- 目录与媒体统一网格：目录卡片 = 封面拼贴/首图 + 目录名 + 项目数；媒体 = 缩略图。目录排在媒体前（现有逻辑保留）。
- "包含子文件夹"开关移入顶栏更多菜单（默认开启），切换时保留滚动位置。
- 空态/加载更多/错误重试统一风格；进入/退出使用共享元素或淡入淡出（不要求复杂动画，避免卡顿）。
- 返回手势：目录内返回上一级；到根再返回退出页面（现有 BackHandler 语义保留）。

### 4.3 相册/图片网格 AlbumScreen
- 目录内图片按日期分组（月/日标题），网格更紧凑；封面视频混排时显示时长。
- 点击图片进入沉浸查看器，传入当前列表与索引，支持左右滑动切换。

### 4.4 图片查看器 V2ImageViewer
- 纯黑背景、edge-to-edge、系统栏自动隐藏；单击切换控件，双击/双指缩放；缩放状态下拖动查看，边界回弹；下滑关闭（缩放为 1 时）。
- 横滑切换上一张/下一张（预加载相邻 1–2 张）；顶部：返回 + 文件名 + 更多（信息/收藏/待删除）；底部：进度"12 / 240" + 操作栏（收藏、加入待删除、分享/打开方式按现有能力）。
- 信息弹层：尺寸、大小、路径仅相对路径/库名（不暴露绝对路径）、时间、来源、是否待删除。
- 视频：点击进入现有播放器（不在查看器内重写播放器）。
- 动画：进入/退出使用容器变换或淡入淡出；避免黑屏闪烁。

### 4.5 批阅模式 V2ReviewScreen
- 视觉极简：顶栏只保留返回 + 进度（已批/总数 + 细进度条）+ 更多；底部固定动作区（保留/待删除/撤销/上一项/下一项），按钮更大、间距合理。
- 预览优先：图片全屏可缩放；视频保留现有播放能力并显示关键控件；加载下一页时保持当前画面不闪。
- 手势：左右滑切换上一项/下一项；上滑/下滑（可选）标记保留/待删除，需明确提示并可撤销（Snackbar/撤销按钮）。
- 进度与导航：明确"第 N / 共 M"，已批数量、剩余数量；断点恢复提示；快进/后退一屏。
- 批量：长按进入多选（P3 可选，若时间不足放 P4）。
- 保持现有批阅数据语义（keep/delete 决策、待删除队列、批阅会话恢复）；不得改变服务端契约。

## 5. 设计系统改造（P1 基础）

- `ui/theme`：更新颜色（深色为主、少量品牌色）、Typography（标题/正文/说明）、Shapes（圆角 2/6/12/20）、Spacing（4/8/12/16/24）、Motion（标准时长 150/250/350ms）。
- 新增可复用组件（`feature/v2/ui/components`）：
  `MediaThumb`、`FolderTile`、`SectionHeader`、`FilterChipRow`、`EmptyState`、`ErrorState`、`LoadingSkeleton`、`TopBar`、`BottomActionBar`、`ProgressHeader`、`ImmersiveOverlay`。
- 统一深色/浅色（若现有仅深色则保持深色，避免扩大范围）。
- 统一图标使用 Material Icons（现有依赖），不新增图标库。

## 7. 约束与非目标

- 不改 Server、API Contract、数据库、迁移、删除安全语义。
- 不新增网络/图片/动画重型依赖；如需新增依赖必须先由 Lead 确认。
- 不改变 ViewModel/Repository 的公开行为（分页、缓存、数据源、会话恢复）；UI 重构不得以"简化"为名删除功能。
- 不删除或弱化安全门禁（can_delete、pending 删除、确认流程）。
- 不重写播放器内核；视频播放保持现有 Media3/GSY 路径。
- 版本号/Release Notes 在 P5 单独处理，本计划不改版本。
